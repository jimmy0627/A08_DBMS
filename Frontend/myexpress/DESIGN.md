# Design System Inspired by Arknights (Rhodes Island Database)

## 1. 視覺主題與氛圍 (Visual Theme & Atmosphere)

這套網頁設計系統深刻還原了《明日方舟》遊戲中的「羅德島終端機（PRTS）」介面。整體視覺傳達出**戰術性、醫療工業風、以及極致的冷靜與克制**。頁面以深邃的暗黑/深灰為基底，搭配高對比的青色（Teal）與警示紅（Red），創造出宛如身處羅德島艦船內部操作機密數據庫的沉浸感。

排版上大量運用了「雙語對照」與「偽代碼註釋（如 `// TERMINAL`）」的裝飾性手法，這也是明日方舟 UI 的靈魂所在。介面極度扁平化，幾乎摒棄了所有圓角（0px border-radius）與漸層陰影，取而代之的是銳利的幾何切割、極細的邊框線條（1px solid），以及隱約浮現的六邊形（Hexagon）或細胞狀的水印背景。

**核心特徵：**

* **終端機美學（Terminal Aesthetic）：** 大量使用 `//` 作為英文副標題的開頭，營造指令列風格。
* **羅德島青（Rhodes Teal）作為視覺焦點：** 僅用於關鍵交互（按鈕、高亮標籤、當前進度），絕不濫用。
* **極致的銳利感：** 幾乎 100% 的 0px 圓角（僅影音播放鍵等極少數例外），呈現工業與戰術的嚴謹。
* **模塊化卡片：** 資訊被嚴格收納在帶有極細邊框或微小色差的深色矩形面板中。
* **雙語資訊層級：** 大字體繁體中文搭配全大寫、增加字距（Tracking）的微小英文，形成強烈的主從對比。
* **水印與底紋：** 面板背景偶爾帶有巨大的引號 `99` 或六邊形暗紋，增加細節層次而不干擾閱讀。

## 2. 色彩配置與角色 (Color Palette & Roles)

### 全域變數定義 (Global CSS Variables)

```css
:root {
  --teal: #29b6f6;       /* 羅德島青: 核心互動、進度指示 */
  --red: #d32f2f;        /* 危機紅: 警示、Breaking News、刪除/登出 */
  --gold: #f0c14b;       /* 幹員金: 高星級、珍稀物資 */
  --text: #ffffff;       /* 主文本 */
  --muted: #888888;      /* 元數據、副標註 */
  --border: #2a2a2a;     /* 模塊邊框 */
  --bg-deep: #050505;    /* 全局背景 */
  --bg-panel: #111111;   /* 面板背景 */
}
```

### 主要品牌色 (Primary Brand)

* **深淵黑 (Deep Black, `--bg-deep`)：** 最底層的頁面背景色。
* **羅德島青 (Rhodes Teal, `--teal`)：** 代表技術、醫療與連通性。用於核心互動按鈕 (`.btn-teal`)、當前分類高亮、以及關鍵數據標籤。
* **純白 (Pure White, `--text`)：** 用於各級標題與主要閱讀內文。

### 中性色階 (Neutral Scale)

* **面板深灰 (Panel Dark Grey, `--bg-panel`)：** 所有 `.panel` 組件的背景色，通常伴隨 `1px solid var(--border)` 的邊框。
* **次要灰 (Meta Grey, `--muted`)：** 用於所有帶有 `//` 前綴的英文標註、幹員 ID、以及較輕量的裝飾文本。
* **邊框灰 (Border Grey, `--border`)：** 用於網格系統中的虛擬切割線。

### 狀態與警示色 (Interactive & Alert States)

* **危機紅 (Crisis Red, `--red`)：** 高強度的視覺警示。
    * 應用場景：首頁的 `BREAKING NEWS` 區塊、管理員刪除按鈕、以及 `LOGOUT` 登出選項。
    * 風格要求：背景通常伴隨低透明度的紅色填充 (`rgba(211, 47, 47, 0.1)`)。
* **六星璀璨黃 (Operator Gold, `--gold`)：** 專用於幹員星級（6-Star）展示與稀有資源。
* **互動懸停 (Hover)：** 按鈕在懸停時實施「顏色填滿」或「亮度提升 10%」的視覺反應。

## 3. 排版規則 (Typography Rules)

### 字體族群 (Font Families)

* **中文 (Primary TC)：** `Noto Sans TC`, `Microsoft JhengHei`。在頁面關鍵組件（如按鈕、標題）應強制使用粗體。
* **英文與數字 (Data EN)：** 優先使用 `JetBrains Mono` 或 `Monospace`。特別是用於 ID、數值、以及帶有 `//` 前綴的裝飾標籤。

### 資訊層級 (Hierarchy)

| 角色 | 大小 | 字重 (Weight) | 顏色 | 規範 |
| --- | --- | --- | --- | --- |
| **頁面主標題** | 2.5rem+ | 800+ | `--text` | 絕對的視覺中心，右側通常附帶 `// 描述` |
| **區塊副標題** | 0.85rem | 800 | `--teal` | 必帶前綴 `//`，全大寫，`letter-spacing: 0.2em` |
| **屬性標註** | 0.75rem | 800 | `--muted` | 用於 `ILLUSTRATOR //` 這類欄位名稱 |
| **標籤文字** | 0.8rem | 800 | 自定義 | 直角填充背景中的文字必須極其清晰 |
| **數據內文** | 0.95rem | 400-500 | `--muted` | 行高 1.8-2.0，確保長篇文章的易讀性 |

### 排版原則 (Principles)

* **終端機雙斜線 (`//`)：** 這是系統最重要的特徵。
    * **前綴型：** 用於區塊描述（例：`// CHARACTER DESCRIPTION`）。
    * **中間型：** 用於雙語對照（例：`USER PROFILE // 身份檔案`）。
    * **後綴型：** 用於操作提示（例：`ILLUSTRATOR //`）。
* **極高字重：** 為了抵消深色背景對視覺的侵蝕，關鍵導航與按鈕文字應鎖定在 `font-weight: 800`。
* **全大寫 (Uppercase)：** 所有裝飾性英文標註必須使用全大寫。

## 4. 組件樣式 (Component Stylings)

### 按鈕系統 (Button System)

* **羅德島端子 (`.btn-filled.btn-teal`)：** 以 `var(--teal)` 填滿背景，黑色文字。代表正常的系統確認、進入、或核心流程。
* **危機操作 (`.btn-red`)：** 以 `var(--red)` 作為背景或邊框。代表具備風險的操作，如「登出」、「刪除記錄」或「終止任務」。
* **次要線框 (`.btn-outline`)：** 僅有 1px 邊框，內部透明。用於取消、返回或非主要導航。

### 模塊化面板 (.panel)

* **幾何定義：** 必須為 `border-radius: 0;`。
* **左側導軌：** 大多數主要面板左側應有一條 4px 的配色條（通常為 Teal 或 Border Grey）。
* **背景填充：** `background: var(--bg-panel);` 搭配 `rgba(255,255,255,0.02)` 的微弱疊加。
* **組合規則：** 所有頁面的核心內容（如登入框、個人信息、技能列表）必須包裹在 `.panel` 中以維持視覺的一致性。

### 數據格點系統 (Data Grid)

* **快速連結 (Quick Links)：** 採用 3 欄式 Grid 佈局，每一格為直角按鈕，包含大文字標題與小文字 `// SUB`。
* **列表標籤 (Labels Bar)：** 數據列表（如幹員列表）頂部必須有灰色的標籤列（如 PORTRAIT, BASIC INFO），字體需全大寫且加重字距。



### 警告與特殊區塊 (Alert & Warning Blocks)

* **紅區 (Danger Zone)：** 邊框 `#D32F2F`，背景為極暗的半透明紅色，字體為細小灰色或紅色。用於刪除文章等不可逆操作。

## 5. 佈局原則 (Layout Principles)

### 空間與網格 (Grid & Space)

* **儀表板佈局 (Dashboard UI)：** 畫面被切割成多個方塊，彼此之間的間距（Gap）一致且緊湊（通常為 16px 或 24px）。
* **側邊欄主導：** 檔案室與攻略介面常採用「左窄右寬」或「上寬下分欄」的經典數據庫佈局。

### 留白哲學 (Whitespace Philosophy)

* **緊湊的數據區：** 屬性面板（HP, ATK, DEF 等）排列緊密，資訊密度極高。
* **呼吸感的標題區：** 大標題（如 H14-4 突襲）周圍會留出較大的深色空間，以凸顯壓迫感與戲劇張力。

## 6. 深度與層級 (Depth & Elevation)

| 層級 | 處理方式 | 應用場景 |
| --- | --- | --- |
| **Level 0 (底層)** | 微弱細胞紋理/六邊形圖案的純黑背景 | 全局背景 |
| **Level 1 (容器)** | 深灰底色 (`#111` ~ `#1A1A1A`)，無陰影 | 內容卡片、側邊欄 |
| **Level 2 (浮層/交互)** | 1px 青色或黃色高亮邊框，純色填滿 | 懸停狀態、重要按鈕、六星幹員外框 |

**陰影哲學：** 幾乎**不使用** CSS `box-shadow`。介面的前後層級完全依靠背景明暗度（深黑 vs 深灰）與高亮邊框來區分。這賦予了網頁一種「玻璃螢幕內發光」的終端機真實感。

## 7. Do's and Don'ts (設計守則)

### Do (必須做)

* **前綴標準化：** 在區塊標題前或副標註中使用 `//` (Slash-Slash)。
* **極端粗細對比：** 標題儘量使用 `800` 字重，而副標註使用 `0.7rem` 的微型字體。
* **鎖定直角：** 所有的按鈕、輸入框、圖片容器必須是 0px 圓角。
* **色彩語義：** 登錄/確認使用 Teal，警告/退出使用 Red。

### Don't (絕對避免)

* **禁止使用圓角：** 即使是 2px 或 4px 的輕微圓角也會破壞工業感。
* **禁止使用過時符號：** 單斜線 `/` 或單冒號 `:` 應儘量升級為雙斜線 `//` 以符合 PRTS 2.0 規範。
* **禁止過度對齊：** 不要讓所有中文標題居中，盡量保持靠左對齊以模擬數據報告。
* **禁止使用非主題色：** 避免使用原生藍色（預設 Link）或紫色，應一律導向 `var(--teal)` 或 `var(--muted)`。

## 8. 響應式行為 (Responsive Behavior)

### 斷點策略 (Breakpoints)

* **Desktop (>1024px)：** 完整的多欄位終端機佈局（如幹員列表右側直接顯示詳細資料）。
* **Tablet (768px - 1024px)：** 側邊欄折疊，幹員列表改為兩欄式網格。
* **Mobile (<768px)：** 所有模塊轉為單欄垂直堆疊（Stack）。主視覺標題縮小，裝飾性的英文副標題可視情況隱藏以節省空間。導航列收合為純粹的漢堡選單。

## 9. Agent Prompt Guide (AI 提示詞指南)

### 快速色彩參照

* Bg_Base: `#0A0A0A`
* Bg_Panel: `#181818`
* Accent_Teal: `#29B6F6`
* Accent_Red: `#D32F2F`
* Text_Primary: `#FFFFFF`
* Text_Secondary: `#888888`

### 組件生成提示詞範例 (Example Component Prompts)

* **生成標題區塊：** 「建立一個明日方舟風格的標題區塊。深色背景，左側有一條 3px 寬的青色垂直線。主標題為 20px 純白字體粗體。標題上方需要有一行字號 12px、顏色為灰色的全大寫英文，前綴包含 `//` 並增加字母間距。」
* **生成戰術按鈕：** 「設計一個 0px 圓角的按鈕。背景透明，帶有 1px 的灰色邊框。文字為白色居中。當 Hover 時，背景瞬間填滿為 `#29B6F6` (青色)，文字保持白色，無過渡動畫以呈現機械感。」
* **生成數據面板：** 「建立一個幹員數值卡片。背景 `#181818`，無圓角。內部劃分網格，顯示 HP、ATK、DEF。數值使用白色粗體字 18px，屬性標籤使用灰色 12px 英文小寫。整體被一個極細的 `#333333` 邊框包圍。」
* **生成警告區塊：** 「建立一個管理員操作區塊。背景使用帶有 10% 透明度的暗紅色，邊框為 1px 的亮紅色 `#D32F2F`。左上角帶有一個紅色的警告圖標。內部放置兩個 0px 圓角的按鈕，一個背景透明帶灰框，一個背景為深紅色。」
